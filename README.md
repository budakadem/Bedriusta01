# Bedri Usta Mannheim Website

Premium Bedri Usta Mannheim landing page built with React, TypeScript, Vite, and React Native Web.

## Local Development

```bash
npm install
npm run dev
```

Local URL:

```text
http://127.0.0.1:5173/
```

## Production Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Deployment

Recommended settings for Vercel or Netlify:

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Node package manager: npm
