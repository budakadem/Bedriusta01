## Observed Original
- Header has split navigation around a central Bedri Usta logo.
- Fonts observed: `Heebo` and `Karla`.
- Main palette is warm white/cream, black text, muted grays, and Bedri Usta red.
- Original home view strongly features Bedri portrait/logo and branch cards.

## Requested Changes
- Build as a React Native Web page instead of the original WordPress layout.
- Do not include `Subelerimiz` / branch section.
- Add a footer.
- Use the supplied Bedri Usta image palette: deep burgundy, cream, warm brown.

## New Page Flow
1. Fixed premium header: logo-centered brand signal, no `Subeler` link.
2. Hero: dark burgundy editorial landing with Bedri brand image and reservation CTA.
3. Story: portrait-led Bedri Usta copy inspired by the original homepage text.
4. Menu highlights: kebap, meze, lahmacun, tatli as premium feature tiles.
5. Craft section: charcoal/fire/copper-toned proof points.
6. Visit/contact CTA.
7. Footer with brand, links, hours, social/contact.
